# 国际影片征集审定

维护国际影片报名、版本、权利和评审决定。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括影片报名、媒体版本、权利声明、补件记录、评委评分、审定结果，状态示例为已报名 → 待补件 → 可评审 → 评审中 → 已撤回 → 已审定。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 电影节收到大量国家和地区的影片报名
- 活动包含金丝路奖评选
- 主宾国机制带来更多跨国电影合作

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
