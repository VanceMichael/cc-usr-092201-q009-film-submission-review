# 国际影片征集审定

维护国际影片报名、版本、权利和评审决定。面向来自一百三十九个国家和地区的两千多部影片，
解决同源版本重复（导演剪辑版、不同字幕、多个报名主体）、分项材料审定、回避与授权访问、
评分复核以及结论隔离与证据回查。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。记录类型包括
影片报名、媒体版本、权利声明、补件记录、回避关系、评委评分、复核记录、审定结果、公布记录；
状态示例为 已报名 → 待补件 → 可评审 → 评审中 → 已撤回 → 已审定。样例使用虚构标识，
不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 电影节收到一百三十九个国家和地区的两千多部影片报名
- 同一作品可能以导演剪辑版、不同字幕和多个报名主体重复出现
- 活动包含金丝路奖评选
- 主宾国机制带来更多跨国电影合作

## 审定后台（`review/`，纯标准库）

- `audit.py` — 只追加的哈希链事件日志。补件、撤回、换版、调单元、评分及更正、复核、
  审定、通知、公布全部是追加事件；状态由重放得到，任何删改在 `verify_chain()`/载入时暴露。
- `rules.py` — 按届与版本不可变的章程（必填分项、单元、奖项单元、参评国家地区）。
  新章程以新版本公布，旧结论永远回查到报名时适用的版本。
- `models.py` / `projector.py` — 事件重放得到的读模型。
- `service.py` — 应用服务与全部业务规则：
  - 报名分项保存主创、联合制作权利、国家地区、首映状态、放映授权、字幕、技术规格、报名声明；
    `readiness_report()` / `missing_materials()` 让可审文件与缺件一目了然。
  - 文件以 SHA-256 摘要登记；`same_origin_groups()` 按摘要、作品源标识与片名主创做并查集聚类，
    同一报名主体重复报名被拒绝，不同报名主体保留并聚类，换版停用旧版但整条留档。
  - `declare_conflict()` 必须在 `assign_judges()` 之前生效，存在回避整体拒绝并追加拦截记录；
    缺件、已撤回的影片不能进入分配。
  - `access_media()` 校验“已分配 + 未撤回 + 无缺件 + 授权范围覆盖用途 + 有效文件”，
    评委只能接触获授权内容，越权尝试追加 `access_denied` 事件。
  - 评分独立提交；更正只追加并指向原评分事件；审定要求全部评委已独立评分且无未结复核。
  - 改判必须走“发起复核 → 复核结论为推翻原结论”，通知前结论对非组委会角色隔离
    （`SecrecyError`）；公布前再次校验有效文件、独立评分与复核结案。
  - `evidence_package(sid)` 从任一结论回查：适用章程版本、各分项材料、有效影片文件与全部版本、
    每位评委的独立评分及更正链、复核过程、完整审计轨迹。
  - `save()`/`load()` 以事件流 JSON 持久化，载入即校验哈希链。

## 本地校验

```
python -m unittest discover -s tests
```

测试会读取公开领域资料，并对后台执行端到端规则检查（同源聚类、回避前置、授权访问、
追加更正、隔离公布、证据回查、篡改检测、事件重放）。后续服务应继续兼容这份公开资料约定。
