# 国际影片征集审定

维护国际影片报名、版本、权利和评审决定。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`（当前为版本 2）。

记录类型包括：影片报名、媒体版本、权利声明、国家地区、首映状态、放映授权、字幕信息、技术规格、报名声明、补件记录、回避声明、评委评分、追加记录、审定结果、结果通知。

流程状态示例为：已报名 → 待补件 → 可评审 → 评审中 → 已撤回 → 已审定 → 结果隔离 → 已通知。

这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

## 治理约定

`policies` 固化组委会的审定规则，样例与后续服务都必须满足：

- **同源版本识别**：媒体版本以 `sha256` 文件摘要识别同源上传。同一作品的导演剪辑版、不同字幕版、多个报名主体的重复上传分别登记（`upload_seq` 连续），不被“最后一次上传”覆盖，全部保留作为参评依据。
- **事实分存**：主创权利与联合制作权利、国家地区、首映状态、放映授权、字幕、技术规格、报名声明各自独立保存，不合并成一条报名记录。
- **可审文件与缺件**：`reviewable_files` 与 `missing_items` 分别列明当前可审文件和缺件；评委可审文件必须同时是有效版本且在放映授权范围内。
- **回避先生效**：回避声明标记 `effective_before_assignment`，在分配影片前生效；被回避评委不得出现在评分人中。
- **追加记录**：补件、撤回、换版、调整单元、更正评分只以 `append_records` 追加（序号从 1 连续），不覆盖历史；更正评分须指向已有独立评分并记录前后值。
- **结果隔离**：未入选结论带 `isolated_until`，正式通知前保持隔离。
- **结论回查**：每个审定结果回指适用章程（`regulation`）、有效影片文件（`valid_media`）、独立评分（`score_ids`）与复核过程（`review_process`）。

已整理的业务事实：

- 电影节收到大量国家和地区的影片报名
- 活动包含金丝路奖评选
- 主宾国机制带来更多跨国电影合作

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明，并对上述治理约定做正向与反向校验（丢弃同源重复、越权可审、被回避评委评分、追加记录断号、未入选未隔离等都会被拒绝）。

```bash
python -m unittest discover -s tests
```

后续服务应继续兼容这份公开资料约定。
